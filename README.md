**AGENTS** — задаёт общие правила работы, ограничения, порядок согласования и выбор инструкций для конкретной задачи.

**ux-audit** — определяет методику UX-аудита, критерии проверки и формат результатов.

**ui-writing-policy** — задаёт редакционные правила, терминологию и тон текстов интерфейса.

**typography** — регулирует проверку и исправление русской типографики без изменения формулировок.

**layout-assembly-guidelines** — описывает правила сборки интерфейсов из компонентов, адаптации и проверки макетов.

**canvas-guidelines** — определяет, какие правила оформления холста применять в зависимости от UI кита.

**canvas-mobile** — задаёт размещение мобильных макетов на холсте, оформление секций, переходов и пояснений.
